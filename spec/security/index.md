# Security and private reporting

The policies in PRD sections 2, 8, 9 and 10 govern confidential intake,
repository admission and human decisions. Evidence identity, data durability,
current authority and human approval remain separate facts.

- [Admission scan](./admission.md)
- [Project restrictions](./enforcement.md)
- [Private intake](./intake.md)
- [Case decisions](./cases.md)
- [Shared evidence retention](./evidence.md)
- [Private access and retention](./privacy.md)

The legacy models under `formal/models/vetting` and `formal/models/api` supply
source-bound scenarios. These specifications state the replacement domain
contracts. Database transactions, cryptographic digests, GitHub authority,
provider responses and storage integrity require real adapters and conformance
evidence during implementation.
