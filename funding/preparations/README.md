# Funding preparations

These compact reviewed inputs are historical preparation artifacts for the
removed monthly-pool payout review. They are never canonical cycle proposals,
funding records, approval, wallet-control evidence, or payment authority.

The importer and the monthly preparation workflow were removed with the
legacy funding mode on 18 October 2026. The only remaining reader is the
contribution-quality validator (`bun run quality:check`), which binds each
file in `../quality/` to the preparation with the same name.

The August 2026 preparations were removed on 18 October 2026 with the projects
listed before the D1 registry. They remain in Git history.
